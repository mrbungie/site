## Intuición clave

Un árbol individual es inestable: un cambio pequeño en los datos puede alterar mucho su estructura (alta varianza). El bosque reduce ese problema promediando árboles distintos entre sí. Para lograrlo, cada árbol se entrena con:

- una muestra **bootstrap** de las filas (con reemplazo), y
- un subconjunto aleatorio de variables en cada división.

Promediar árboles poco correlacionados baja la varianza sin aumentar mucho el sesgo. Además, las filas que quedan fuera de cada muestra bootstrap (*out-of-bag*) sirven como validación gratuita.

## Qué observar

- Cada árbol usa reglas parecidas, pero no idénticas.
- La decisión final depende de la **agregación**, no de un solo árbol.
- Se gana robustez a costa de perder una explicación global simple.
